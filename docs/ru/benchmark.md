# Бенчмарк

Измерялась библиотека `yii2-extensions/etcd` 2.0.0, коммит `6797620` в `main`.

Медиана из трёх прогонов. Время в миллисекундах. Память — пик RSS (`VmHWM`) процесса PHP этой серии, в МиБ.

Холодный клиент — это новый объект `Etcd` на каждый вызов внутри одного процесса, а не новый процесс PHP. Итерации после отброшенного прогрева: долгий процесс и сырой вызов 800, холодный клиент 120, тела 128 Б / 8 КБ / 256 КБ — 600 / 300 / 80, диапазоны 1 / 100 / 1000 ключей — 300 / 120 / 40, auth без обновления токена 400, холодный токен 60, lease 200. Параллельность — окно 3 секунды; ops/s — сумма по всем процессам.

На время прогона включены `opcache.enable_cli=1` и `xdebug.mode=off`. Расширение Xdebug оставалось загруженным. В образе по умолчанию `opcache.enable_cli=Off`.
